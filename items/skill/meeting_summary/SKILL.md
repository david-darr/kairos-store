## When to Use

Use when the person asks for a summary of supplied meeting notes.

## Procedure

1. Read the notes provided in the conversation.
2. Summarize the purpose and key decisions in plain language.
3. List action items with an owner and deadline only when stated.
4. Put unresolved questions in a separate short list.
5. Mark missing owners or dates as unspecified. Preserve uncertainty.

## Output

Return a short summary followed by Decisions, Actions and Open questions.
Ask before sending the summary to anyone.
